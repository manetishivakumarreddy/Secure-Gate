    System Information

    SecureGate parses local synthetic JSON, applies schema and policy checks, then records each decision to a local JSON Lines audit file. Accepted messages update the in-memory replay state; commands are never executed.

    • Telemetry sender allowlist: SENSOR-01, SENSOR-02, SENSOR-03.
    • Temperature: -40 to 120 (illustrative units); voltage: 0 to 60 (illustrative units); signal strength: integer 0 to 100.
    • Timestamps must include a timezone, be no more than 300 seconds old, and no more than 60 seconds ahead.
    • Sequence numbers must increase per sender. Duplicate message IDs and replayed sequences are rejected while replay protection is enabled.
    • Commands: STATUS_CHECK, SENSOR_READ, DIAGNOSTIC_PING, TELEMETRY_REQUEST. These values describe harmless simulated actions only.

    Validation is not authentication. No real device or network integration is present. The local audit log is not tamper-proof; replay state resets when the app restarts. All numeric limits are illustrative, not operational safety thresholds.
